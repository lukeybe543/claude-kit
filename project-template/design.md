# Design — <project>

**This is the architecture and the source of truth.** Settled shape and plain
description belong here. A claim that is still being tested, still under
debate, or was said with more force in conversation than meant does **not**
belong here as flat prose — it belongs in `docs/decisions.md` with a Band, so
it stays `revisitable` or `mixed` instead of silently being read as fact. If
you are about to write "must" / "always" / "never" in this file, stop: is
this a decision (→ decisions.md) or a description of what already is (→ stays
here)?
